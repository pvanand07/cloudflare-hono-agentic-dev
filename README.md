# Project Template

Hono on Cloudflare Workers. `wrangler dev` for local development — no Vite, no separate dev toolchain. Server-rendered JSX pages, D1 + Drizzle for data, `@hono/zod-validator` for request validation.

## Setup

```bash
npm install
npx wrangler d1 create project-template-db
# paste the returned database_id into wrangler.jsonc
npx wrangler d1 migrations apply project-template-db --local
```

## Run

```bash
npm run dev
```

Visit http://localhost:8787. API routes are under `/api/*`.

## Database changes

```bash
npx drizzle-kit generate
npx wrangler d1 migrations apply project-template-db --local   # or --remote
```

## Typegen

Regenerate `worker-configuration.d.ts` after changing `wrangler.jsonc` bindings:

```bash
npm run cf-typegen
```

## Deploy

```bash
npm run deploy
```

## Structure

- `src/index.tsx` — Worker entry, mounts page and API routers
- `src/renderer.tsx` — `hono/jsx-renderer` setup
- `src/routes/api/` — `@hono/zod-validator`-validated API routes
- `src/routes/pages/` — JSX page routes
- `src/db/` — Drizzle schema and D1 client
- `migrations/` — generated by `drizzle-kit`
- `public/` — static assets, served via Workers Static Assets
- `docs/` — domain and architecture docs
- `AGENT.md` — agent workflow instructions

## Testing

No test runner is wired up. `@cloudflare/vitest-pool-workers` didn't work reliably against this stack's dependency versions at the time of writing — check the package's current docs before adding it. Verify changes with `npm run dev` and manual requests until it's confirmed working.

## Keeping this stable

- Dependency versions in `package.json` are pinned exactly, not with `^`/`~`.
- CI only runs checks known to work: install from the lockfile, typecheck, `wrangler deploy --dry-run` (validates the Worker actually bundles).
- Migrate locally first, always. Treat `--remote` as a deliberate, separate action.
- After any `wrangler.jsonc` change, rerun `npm run cf-typegen` before touching bindings in code.
